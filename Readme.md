## What is it?

FlipFlip is "a glorified slideshow, with *lots* of bells and whistles". This repository is the
**mobile** version (`FlipFlip+`) built on Capacitor 8, sharing the same modern renderer as the
[desktop version](https://github.com/lospanditasmarinel12-lgtm/FlipFlip-Electron):
React 18, MUI 6, Webpack 5, TypeScript 5, Zustand + Immer.

Highlights:

- **Native iOS and Android apps** with safe-area, splash screen and app storage
- **Media Optimizer** (`flipflip-transcoder`, iOS + Android): heavy camera media
  (HDR, > 1920 px, HEIC/HEIF, > 8 MB images; HDR, > 1080p, > 100 MB or > 20 Mbps videos)
  is converted to **SDR 1080p** on import so slideshows run smoothly on phones
- **Manual "Optimize Existing Library…"** flow (Settings → General) to convert media
  already in your library on demand
- **Haptic feedback** on the phone's own Bluetooth (Buttplug protocol), including
  system-audio capture via a native meter sidecar (Android Visualizer/MediaProjection,
  iOS ReplayKit Broadcast)
- Remote scrapers kept functional for 2026 (e621, Danbooru/Gelbooru/Rule34, EHentai,
  Luscious, BDSMlr, Hydrus, Piwigo, …)

## Build from source

Requires Node.js 18+, npm, and Xcode (iOS) or Android Studio (Android).

```bash
npm ci                            # legacy-peer-deps is set in .npmrc
npm run production                # web app bundle → dist/ (webDir)
npx cap sync android              # copy web assets + sync native scaffolding
npx cap sync ios
```

Then open in the native IDE and run:

```bash
npm run open:android              # opens Android Studio
npm run open:ios                  # opens Xcode
```

Native plugins live in [`plugins/`](./plugins) (Swift/Java sources; their
`.build/` artifacts are gitignored and regenerated by the IDE / SPM).

### Signing notes

- **Android:** the release keystore is **never committed**. To build a release, create
  your own keystore and point `android/keystore.properties` at it.
- **iOS:** the published `.ipa` is development-signed for sideloading (re-sign with your
  own Apple ID via AltStore/Sideloadly/Feather).
